This folder contains the source data for Figure 5.

- spatial_deposition_Cd.shp and spatial_manure_Cd.shp :
  Point-based Cd input of deposition and manure (g ha−1 yr−1) used as input for spatial interpolation.
  Columns include: ID, X, Y, BNPR, BNPRLopt1, BNPRLopt2.

- Qiyang_county.shp:
  Boundary of Qiyang County.

- rice_cover.tiff:
  Rice cultivation mask used to define interpolation grid at 1km * 1km.

Coordinate reference system EPSG:4326.
